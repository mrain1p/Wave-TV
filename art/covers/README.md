# Placeholder cover art

Six square covers, 1400×1400 PNG, in the Wave TV palette.

These are original geometric artwork generated for this repository. They
contain no photography, no third-party artwork, no album art and no licensed
material of any kind, and they are covered by the same [MIT licence](../../LICENSE)
as the rest of the repository.

They exist so a station has something to show — in the picker's now-playing
panel and in store screenshots — without borrowing a commercial release's
cover. Point a show or a track at one of these, or use them as station
artwork.

| File | |
| --- | --- |
| `01-rings.png` | Concentric rings, cool centre warming outward |
| `02-spectrum.png` | Bar spectrum, full bleed |
| `03-horizon.png` | Arc rising over a ruled horizon |
| `04-matrix.png` | Dot matrix with radial falloff |
| `05-split.png` | Diagonal split with offset discs |
| `06-bands.png` | Stacked waveform bands |

Regenerate or restyle them from `art/icon.svg`'s palette: field `#0B0B0C`,
tile `#111113`, peak `#F2F0EC`, warm `#E0533D`, cool `#4A8B8D`.
